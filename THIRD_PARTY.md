# Third-party components

The application has no runtime dependencies beyond Python 3.11+ and its standard
library (Python Software Foundation license). No external code, media, datasets,
or vendored dependencies are included. Examples and test data are original,
synthetic fixtures. The project code is MIT licensed.

Build/check tools are not bundled into the application: setuptools (MIT), build
(MIT), Ruff (MIT), packaging (Apache-2.0 OR BSD-2-Clause), pyproject-hooks (MIT),
and colorama on Windows (BSD-3-Clause). GitHub Actions uses checkout and
setup-python (MIT), pinned to audited upstream commit references. These licenses
are compatible with this project's distribution; their own notices remain in
their separately installed distributions. No ownership claim is made over them.
