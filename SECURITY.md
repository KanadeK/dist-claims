# Security policy

Version 0.1.x receives fixes on the default branch. For a vulnerability, use
[private vulnerability reporting](https://github.com/KanadeK/dist-claims/security/advisories/new).
If that form is unavailable, open an issue requesting a private contact channel
without exploit details or sensitive files. Do not publish private input.

This tool is an offline diagnostic, not a sandbox or a complete security audit.
Only inspect files you are authorized to read. Use a trusted Python interpreter
and a stable local filesystem. Inputs can be sensitive even when diagnostics
omit their contents; review reports before sharing them.
